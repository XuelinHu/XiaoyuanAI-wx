# 小元 HTML5 展示页

该目录提供一个可直接在浏览器中运行的 HTML5 展示页，用于补充当前仓库的页面联调、演示和截图采集工作。页面内容与仓库中的微信小程序页面保持一致，覆盖以下三个核心视图：

- 会话页
- 历史会话页
- 我的页

## 使用方式

默认推荐在当前目录启动一个本地静态服务：

```powershell
cd D:\workspace\front\XiaoyuanAI-wx\html5
conda run -n pyg python -m http.server 8080
```

然后在浏览器中访问：

`http://127.0.0.1:8080`

如果仅需快速预览，也可以直接打开 `index.html`，但部分浏览器会限制本地脚本能力，因此截图采集时仍建议使用静态服务。

## 截图建议

- 默认进入会话页，可直接采集主界面截图
- 通过底部 Tab 切换到“历史”和“我的”页面后分别截图
- 如需展示动态交互，可在会话页输入文本并点击“发送”
- 所有最终截图统一保存到 `docs/assets/screenshots/html5/`
