# 截图采集说明

## 当前采集策略

本次软著材料改为使用仓库内 `html5/` 目录提供的 HTML5 展示页进行截图采集。该展示页与当前微信小程序代码中的会话页、历史页和我的页保持同构结构，能够在浏览器中稳定呈现页面布局、接口调用方式和核心交互状态，适合作为本轮软件说明书中的运行界面素材来源。

## 启动方式

推荐在 `D:\workspace\front\XiaoyuanAI-wx\html5` 目录启动本地静态服务：

```powershell
cd D:\workspace\front\XiaoyuanAI-wx\html5
conda run -n pyg python -m http.server 8080
```

访问地址：

`http://127.0.0.1:8080`

## 截图页面清单

| 页面名称 | 访问方式 | 说明 |
| --- | --- | --- |
| 会话页 | 默认首页 | 展示助手状态、消息列表、历史加载入口、输入框与发送按钮 |
| 历史会话页 | 底部 Tab 切换到“历史” | 展示历史会话摘要、时间标签和情绪标签 |
| 我的页 | 底部 Tab 切换到“我的” | 展示会话偏好、紧急支持、消息与提醒等配置入口 |
