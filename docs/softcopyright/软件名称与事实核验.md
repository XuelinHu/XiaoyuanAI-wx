# 软件名称与事实核验

## 1. 软件名称候选

1. 小元癌症情绪支持交互软件
2. 小元癌症情绪陪伴服务软件
3. 小元情绪支持会话管理软件
4. 小元健康情绪陪伴软件
5. 小元癌症关怀交互平台软件

## 2. 推荐名称

推荐名称：**小元癌症情绪支持交互软件**

推荐理由：

- 当前仓库同时包含微信小程序主工程和 `html5/` 浏览器展示页，推荐名称不再把登记范围限制在单一运行容器内。
- 核心能力稳定聚焦于情绪支持会话、历史记录浏览和个人支持配置管理，使用“情绪支持交互软件”更准确覆盖实际功能。
- 页面标题、助手角色、服务层接口和本地回退数据均围绕“小元”品牌和癌症情绪支持场景展开，名称与现有代码事实一致。

## 3. 已核验事实摘要

### 3.1 项目形态

当前仓库存在两套已核验的前端表达形式：

- 微信小程序主工程：`project.config.json` 中 `compileType` 为 `miniprogram`，`app.json` 注册了会话页、历史页和我的页。
- HTML5 展示页：`html5/index.html`、`html5/app.js`、`html5/styles.css` 构成可直接运行的浏览器页面，用于页面展示和截图采集。

### 3.2 核心页面与模块

| 模块 | 代码位置 | 作用 |
| --- | --- | --- |
| 会话模块 | `pages/chat/`、`html5/app.js` | 实现会话初始化、消息发送、历史消息补载、助手介绍展示 |
| 历史模块 | `pages/history/`、`html5/app.js` | 展示历史会话列表、摘要内容、时间与情绪标签 |
| 我的模块 | `pages/profile/`、`html5/app.js` | 展示会话偏好、紧急支持、消息提醒等配置入口 |
| 底部导航模块 | `components/bottom-tabs/`、`html5/index.html` | 在会话、历史、我的三页之间切换 |

### 3.3 调用分层

| 层次 | 代码位置 | 说明 |
| --- | --- | --- |
| 配置层 | `config/index.js` | 定义接口网关地址、租户编码、超时和本地回退策略 |
| 请求层 | `utils/request.js` | 封装统一请求入口和失败回退逻辑 |
| 服务层 | `services/chat.js`、`services/history.js`、`services/profile.js` | 将不同业务域拆分为独立调用方法 |
| 页面层 | `pages/*`、`html5/app.js` | 负责生命周期、事件处理和页面渲染 |
| 本地数据层 | `utils/local-data.js` | 为展示环境提供引导消息、历史消息、会话摘要和配置卡片 |

### 3.4 已体现在代码中的接口能力

| 接口功能 | 方法 | 路径 |
| --- | --- | --- |
| 会话初始化 | GET | `/conversation/bootstrap` |
| 助手资料查询 | GET | `/assistant/profile` |
| 历史消息查询 | GET | `/conversation/history` |
| 会话消息发送 | POST | `/conversation/message` |
| 历史会话列表查询 | GET | `/conversation/list` |
| 个人配置卡片查询 | GET | `/profile/cards` |

### 3.5 已核验的交互特征

- 会话页具备欢迎消息展示、文本输入、发送按钮、加载历史消息和消息滚动到底部等交互。
- 历史页展示多条会话摘要，并通过时间与情绪标签反映会话状态。
- 我的页以卡片方式组织会话偏好、紧急支持和消息提醒配置入口。
- 当前前端具备真实接口调用结构，同时保留本地回退数据，使页面在无后端环境下仍可稳定演示。

## 4. 本次截图依据

本次软件说明书中的界面截图采用 `html5/` 目录下的 HTML5 展示页采集，原因如下：

- HTML5 页面与小程序页面共用同一套业务边界和交互结构，适合稳定输出图像素材。
- 浏览器环境更便于按页面维度重复采集、校对和替换截图。
- 截图页与代码事实可一一映射，不需要虚构页面内容。
